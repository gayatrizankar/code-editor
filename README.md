# 🧑‍💻 Code Editor

A sleek, minimal web-based code editor for writing HTML, CSS, and JavaScript with live preview and theme switching.

## 🚀 Features

- 💻 Real-time code editor (HTML, CSS, JS)
- 🔍 Live preview pane updates as you type
- 🌗 Dark / light theme toggle
- 📱 Responsive design for all devices
- 💾 Download your code (optional)

---

## 🛠️ Tech Stack

- HTML5 + CSS3
- JavaScript (Vanilla or React)
- CodeMirror or Monaco Editor *(optional for enhanced editing features)*
